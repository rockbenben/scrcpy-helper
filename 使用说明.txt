========================================
  scrcpy 投屏助手 · 使用说明
========================================

把安卓手机投屏到 Windows 电脑的小工具，基于开源软件 scrcpy。可以用电脑的鼠标键盘操控手机、无线投屏、录屏，还能把手机当电脑摄像头用，或把某个 App 放进电脑上的一个独立窗口里单独跑。免费、开源、无广告。

全程本地直连（数据线，或同一个 WiFi），画面不经过任何服务器；手机端不用 root、不用装 App，只要在开发者选项里打开调试开关（USB 调试，或无线调试）。


----------------------------------------
一、三步开始用
----------------------------------------
1. 把压缩包【解压】到任意文件夹（不要直接在压缩包里运行）。

2. 手机开启「USB 调试」：设置 > 关于手机 > 连续点 7 次「版本号」，返回设置就能看到「开发者选项」，进去打开「USB 调试」。

3. 双击【投屏助手-双击运行.bat】，插上数据线，点「有线投屏」。

首次连接时手机上会弹一个「允许 USB 调试」，点允许即可。窗口顶部会显示「已连接 / 未连接」，连上后还会显示手机型号和安卓版本（如「Redmi Note 11 · Android 13」），一眼就知道哪些功能能用。

如果 Windows 弹出蓝色的「Windows 已保护你的电脑」：刚解压的程序带「网络来源」标记，首次运行可能被拦。助手启动时会自动尝试解除；万一还是弹出来，点弹窗里的「更多信息」>「仍要运行」即可，只需一次。


----------------------------------------
二、能做什么
----------------------------------------
【有线投屏】
  数据线连手机，最简单、最稳定、延迟最低。只连着无线设备时，点它也会直接投那台无线的（名字里的「有线」说的是首选走数据线）。

【无线投屏】
  三种连法，见第三节。

【手机当摄像头】（需 Android 12+）
  只投手机的摄像头画面、不投手机屏幕。可选前 / 后置、横 / 竖屏、旋转 180°（倒置修正）、分辨率、初始倍率、补光灯、麦克风。

  · 手机倒置时勾「旋转 180°（倒置修正）」，在横屏或竖屏基础上再旋转 180°，不是左右镜像。
  · 分辨率只列你这台手机真正支持的档位，不会选到开不起来的。
  · 想用超广角或长焦，就调倍率：投屏中按 左 Alt + ↑ / ↓ 实时变焦，关窗时是多少，助手就记住多少，下次打开面板直接就是那个值。可填范围也按你这台手机上报的读取，不是写死的。（几倍会切到长焦由手机自己决定，各家不同，边按边看画面即可。）
  · 手机亮屏被系统抢走摄像头时会自动重连，不用手动重开。
  · 想在会议 / 直播软件里当摄像头用：Windows 上 scrcpy 不提供虚拟摄像头设备，请用 OBS 之类的软件「窗口捕获」这个画面窗口，再由 OBS 输出虚拟摄像头。

【录制屏幕】
  边投屏边录，存成 mp4 / mkv。文件名自动带时间，不会覆盖上一次。（选 VP8 / VP9 编码时自动改用 mkv。）

【独立窗口】（需 Android 11+）
  在电脑上单开一块屏跑某个 App，手机还能照常用。比例可选竖屏·手机版面 / 横屏·平板版面 / 跟随「设置」里的尺寸 / 自定义宽x高，还有「固定方向」（缓解最大化乱转）。
  声音默认「自动」：同一台手机只让第一个窗口出声，后开的窗口自动静音，避免同一份声音叠成重音；打开时也可改成「播放」或「静音」。
  选 App 时除了内置常用项，还能用「更多应用…」从手机已装列表里挑（可搜索、带中文名，不必查包名），挑完能一键加进自己的常用列表。

【设备管理】
  多台手机的连接、投屏、重命名都在这，见第四节。

【文件管理】
  点主界面右下角「文件」打开手机文件管理器：看手机里的文件（名称 / 类型 / 大小 / 修改时间）、上传（可多选，也可把电脑文件直接拖进列表）、下载（多选后挑一个电脑文件夹）、新建文件夹、刷新、删除。数据走 ADB 直连，手机端不用装 App、不用 root；接了多台手机时，窗口顶部可以切换设备。
  在文件列表里按住鼠标左键拖动就能框选多个文件，文件铺满列表、找不到空白起点时也一样可以从任意一行起手；按住 Ctrl 再框选可在原有选择上追加。单击、双击、把电脑文件拖进来上传都照旧。
  文件列表可以用键盘导航：↑↓ 选文件，→ 或 Enter 进入选中的文件夹，← 返回上一级。打开窗口时焦点就在列表上，不用先点一下；点过按钮后方向键照样有效（导航完焦点会自动回到列表）。焦点在路径框或设备下拉框时，这几个键仍是打字、切设备和「转到」用的，不会被抢。只有恰好选中一个文件夹时才进得去，多选或选中的是文件时按 → / Enter 不会乱跳。
  目录里文件多时，进文件夹和刷新也不会明显变慢：手机端会成批读取一批文件的大小和修改时间，列表也是整批填充，等待时下方会显示「正在读取…」。个别手机不支持批量读取、或正好有文件在读取时被删掉，会自动改用稳妥的逐文件方式重读一次，稍慢一点但不会把大小和时间对错文件。
  没读到完整目录时（手机掉线、ADB 没起来、返回被截断），列表会显示「（打不开这个目录）」并提示确认连接后点「刷新」，不会把「没读到」当成「这个文件夹是空的」。
  「修改时间」是手机上这个文件的最后修改时间，按电脑的本地时区显示（例如 2026-11-07 15:30）。少数老手机或读不到的系统目录会显示「—」，不影响文件本身的显示和操作；安卓文件系统通常不提供创建时间，所以这里给的是修改时间。列表仍按名称排序，点列头不会排序。
  上传 / 下载时，文件列表下方会出现进度条：下载单个文件按「电脑上已收到多少字节 ÷ 手机上文件大小」显示真实百分比；上传、下载整个文件夹或多选时按已完成的项数一格一格前进，只传一个大文件时显示滚动的「传输中」。ADB 被程序调用时不会实时吐进度，所以上传这里不会编一个假的百分比；传完进度条自动收起。中途关窗会立刻停止整批，进度条直接收起，不会显示成 100%。
  文件管理里的防误删：上传 / 下载遇到同名文件会先问「覆盖 / 跳过 / 取消」（默认停在「取消」），不会闷头把原件替掉；删除会列出待删项及类型再确认，只作用于当前目录里选中的那些名字，在内部存储之外的位置还会再确认一次。名称含特殊字符的条目会隐藏并且不可操作，避免删错位置。
  上传 / 下载 / 删除这类批量操作，从开始就把手机和当前目录固定住：处理期间顶部的设备下拉框会锁定并提示「正在处理，等这一批完成再切换设备」，不会把同一批剩下的文件发到另一台手机、或删到别的目录。中途关掉窗口会立即停止整批，不再启动后续项。
  重要提示：删除文件不进回收站、无法恢复！


其它随手可用的：

· 投屏时把文件拖进投屏窗口就传到手机，拖 .apk 进去是安装。（普通文件默认进手机「内部存储 > Download」，电脑这边不弹提示，去手机看即可。）
· 点主界面右下角「快捷键」可查看常用快捷键（全屏、息屏、旋转、复制粘贴等）。
· 关闭助手窗口（×）会一并停止投屏；想让投屏继续、只把助手收起来，请点最小化（–）。正在录屏时会先问你确认，确认后录制正常收尾，文件完整可播。
· 想让最小化后任务栏不占位：到「设置 > 窗口」勾上「最小化时收起到系统托盘」。勾上后点最小化，助手会收进屏幕右下角的托盘区，投屏、录制照常运行；单击或双击托盘图标还原窗口，右键图标可显示窗口或退出助手。
· 助手同一时间只开一个，重复双击只会把已有窗口调到最前。


----------------------------------------
三、无线投屏怎么连
----------------------------------------
点「无线投屏」时，已经连着手机就直接开投；只有没检测到手机时，才会让你在下面三种连法里选。

【插一次线，之后拔掉】（最省事，任何安卓版本都行）
  插线只是借这条已授权的通道，打开手机的无线调试开关并完成授权。开关打开后就能拔线、纯走 WiFi。
  插好线、手机上点过「允许 USB 调试」后点「继续」；这时还没检测到手机，窗口会给你「重试」或改走「输入 IP 连接」，不用退回主界面重来。
  注意：手机重启后这个开关会关掉，需要重新插一次线。

【用配对码】（需 Android 11+，全程不用插线）
  先在手机开「开发者选项 > 无线调试」，点「使用配对码配对设备」，把弹窗里的【IP 地址和端口】和【6 位配对码】照抄进来即可——两项就并排在同一个弹窗里，连接端口助手会自动识别。
  配对码会过期，慢了就重新生成。配一次长期有效，以后重连不用重新配对。

【直接填 IP】（保底连法，不限系统版本）
  填手机 IP（端口一般是 5555）即可，不需要配对码。前提是手机已开着网络 adb：Android 11+ 在「无线调试」里就有；更早的系统先用上面「插一次线」的办法切一次，之后就能纯 IP 连。

连过的设备会自动记住。之后设备没连时直接点「无线投屏」（录屏、摄像头、独立窗口也一样），助手会先自动连回「记住的、当前在线」的那台再开始，不必每次重选连法。连不上时才让你挑连接方式。

老是中途断开？在「设置 > 常用」勾上「自动连接记住的无线设备（开机自动连附近的 · 掉线自动重连）」。


----------------------------------------
四、多台手机怎么管
----------------------------------------
点右上角的连接状态，或右下角「设备」，打开「设备管理」。按钮分两组：

  投屏组  「连接」只负责把没连的设备连上；连上后再点「投屏」开镜像窗口。双击某一行 = 顺手帮你做下一步（没连就连、已连就投）。
  管理组  设为默认（多设备时默认投它）、断开（先关掉这台的投屏窗口、再断掉无线连接；USB 设备请拔线）、重命名（起个好认的名字，如「客厅电视」）、忘记（从「已记住」里去掉，它的自定义名字和默认标记一并清掉；设备还连着时点不动，要先断开或拔线）、不自动连（把某台无线设备移出/恢复自动重连名单）。

想同时投多台：按住 Ctrl 多选后点「投屏」，或直接「全部投屏」。每台各开一个窗口、互不干扰，窗口标题就是设备名（录制和摄像头的窗口会多带「· 录制」「· 摄像头」后缀，一眼能分清）。正在投的会标「▶ 投屏中」，「停止投屏」只关选中那台。

主界面的「有线 / 无线投屏」如果同时连了多台，会让你先挑一台；设过「默认」的直接用默认那台。


----------------------------------------
五、设置里有什么
----------------------------------------
点窗口右下角「设置」。左侧按分类切换，右侧是可调项，改完点「保存」才会记住，下次沿用。

  常用：清晰度、传声音、保持唤醒、投屏关屏、无线自动重连、关助手时断开无线、显示 scrcpy 控制台（调试用）
  画面：帧率、画质（码率）、视频编码（H.264 / H.265 / AV1 / VP8 / VP9）、裁剪画面、解码方式（自动 / 软件解码）、忽略编码器限制（兜底）
  声音：传声音开关、声音来源（外放 / 麦克风）、音频编码
  控制：键盘 / 鼠标模式、只看不控、关窗顺手息屏、显示触摸点、手柄
  窗口：全屏、窗口置顶、无边框、最小化到系统托盘
  独立窗口：分辨率（可自定义）、界面缩放、隐藏系统栏
  录制：保存格式、录制时长、后台录制
  通用：自动刷新状态、其它命令行参数（可选，一般不用填）、自定义 adb / scrcpy 路径（不填=用自带的）

不确定某项是做什么的，把鼠标停在它上面会有中文说明。看不懂的保持默认即可，不影响使用。
改乱了想还原：设置窗口左下角有「恢复默认」，一键复位。

想更省手机的电（只有正在投屏时才真费电）：勾「投屏时关闭手机屏幕」最省电，还能防别人偷看；或取消「保持手机唤醒」，让手机能正常休眠。

关掉助手后手机还连着是正常的，几乎不耗电，重开就能直接用。想关助手时一并断开，勾「关闭助手时断开无线连接」。


----------------------------------------
六、遇到问题怎么办
----------------------------------------
· 双击后窗口一闪而过 / 打不开
  先确认已完整解压、且 .bat 和其它文件在同一个文件夹里。若被杀毒软件或 Windows 拦下，选「更多信息 > 仍要运行」。

· 把文件拖进投屏窗口显示「禁止」图标
  助手正以「管理员身份」在跑——Windows 不允许普通的文件资源管理器把文件拖给管理员权限的窗口。完全关掉助手，改成普通双击【投屏助手-双击运行.bat】重新打开即可（快捷方式里若勾了「以管理员身份运行」也要取消）。助手本来就不需要管理员权限。

· 提示找不到设备
  换一根原装数据线、直插电脑 USB 口（别用扩展坞），并确认手机已打开「USB 调试」。

· 无线连不上
  确认手机和电脑连的是同一个 WiFi。用配对码时还要确认手机停在「无线调试」那一页别退出。若提示「没能自动识别连接端口」，按提示填手机无线调试主界面上那个「IP 地址和端口」里冒号后面的端口号。

· 投屏出来的手机画面发虚模糊（指镜像的手机画面，不是助手界面）
  右键 scrcpy.exe >「属性」>「兼容性」>「更改高 DPI 设置」> 勾选「替代高 DPI 缩放行为」。（助手界面本身已适配高 DPI；若助手界面发虚，多半是旧版本。）

· 画面花屏、偏色或整块变黑
  一般是电脑显卡解码的兼容问题。到「设置 > 画面」把「解码方式」改成「软件解码」再投，就能绕开它（软件解码更吃电脑 CPU，画面正常时保持「自动」就好）。
  若编码选的是 H.265，先确认 scrcpy 是 5.0.1 或更新：5.0 在某些显卡驱动上硬件解码 H.265 会绿屏、花屏，5.0.1 已修好，升级后继续用「自动」就行，不必长期吃 CPU。

· 摄像头打不开，报「Camera configuration error」
  个别超高分辨率档位，手机的视频编码器带不动，scrcpy 会自动逐档降低清晰度重试；一路降到底仍开不出，助手会提示你手动选更低的分辨率。（若读不到支持列表，会退回「高 / 中 / 原始最高」档位，这时高的打不开就选「中」。）

· 摄像头画面上下颠倒
  手机整个倒过来放时，画面会跟着转半圈。在「手机当摄像头」面板里勾「旋转 180°（倒置修正）」——它是在横屏或竖屏基础上再旋转 180°，不是左右镜像。

· 手机一亮屏，摄像头就断开
  安卓的系统行为——亮屏时系统（如人脸解锁）优先级更高，会把摄像头从 scrcpy 手里抢走，scrcpy 挡不住。助手检测到后会自动重连，底部有提示。想少被打断，可在使用期间开勿扰，或关掉「抬起亮屏 / 人脸解锁」。

· 电脑输入法打的中文进不去投屏窗口（只能粘贴）
  scrcpy 与 Windows 输入法的已知限制，输入法「组词」阶段的字 scrcpy 收不到。
  · 临时：在电脑里复制好文字，再到投屏窗口按 Ctrl+V 粘贴。
  · 彻底：给手机装「ADBKeyboard」并设为当前输入法；或在「设置 > 控制」把键盘模式选「游戏模式」，用手机自带输入法打拼音。

· 独立窗口里微信 / QQ 显示不全、字太大、有重影
  应用把虚拟屏当成了平板。打开「独立窗口」时把「窗口比例」选「竖屏·手机版面」即可；若最大化后画面来回乱转，再勾「固定方向」。

· 应用双开 / 分身在独立窗口里黑屏
  安卓的限制——分身跑在另一个用户身份下，且部分应用拒绝在虚拟屏上显示。双开 / 分身请改用普通「投屏」镜像手机主屏，在手机上打开。

· 同一台手机开了多个窗口，只有一个有声音
  这是默认行为：同一台手机只让第一个窗口出声，后开的窗口自动静音，避免几份相同声音叠加成重音。想指定某个窗口出声，开「独立窗口」时把「声音」选成「播放」；先开的窗口关掉后，把窗口全部关了再重开，声音即恢复。

· 文件管理里某个目录打不开，或删不掉里面的东西
  ADB 只能读写它有权限的位置。内部存储（/sdcard 及其子目录，如 Download、DCIM）一般都能读写；系统目录（/system、/data 等）、厂商加密目录、以及正在被占用的文件读不到 / 删不掉，是安卓系统自身的限制，换到自己的文件夹再试。另外：文件管理里的「删除」不进回收站，手机上删掉就找不回来，所以每次都会先弹一次确认。

· 删一个很大的文件夹，中途会不会删一半？
  不会中途超时被掐断：删除用的是不限时的通道，界面也还能刷新。但如果删除过程中你关掉了窗口，或设备端没返回明确结果，助手会立刻停止后续项并弹出「可能只删了一部分」的提示。这时先点「刷新」重新看一遍目录，别直接重试整批，也别以为「报了失败」就等于什么都没删。

· 批量传文件或删除时，切了设备、或直接关了窗口会怎样？
  切设备不会被接受：整批从开始就锁定在开始的那台手机和那个目录，顶部下拉框也会暂时锁住并提示「正在处理，等这一批完成再切换设备」，等这批做完再切。关窗口会立刻中止整批，不再启动剩下的项；已经传过去 / 已经删掉的部分不会自动回滚。重新打开「文件管理」后先点「刷新」看清现状再决定要不要补做，别把整批直接重来一遍（删除尤其不能重试整批）。

· 上传 / 下载时遇到同名文件会怎样？
  会先弹窗列出同名项，三选一：「是」= 覆盖并继续，「否」= 跳过这些同名项、只处理其余的，「取消」= 什么都不做，默认停在「取消」。覆盖后原件找不回来，拿不准就选「取消」或「否」。一次最多处理 200 项，超过会请你分批，避免同名检查漏项。

文件夹里的 scrcpy-helper.ps1、scrcpy.exe 等是程序文件，平时不用打开，只要它们和 .bat 在同一个文件夹里即可。
