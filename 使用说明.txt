========================================
  scrcpy 投屏助手 · 使用说明
========================================

把安卓手机投屏到 Windows 电脑的小工具，基于开源软件 scrcpy。可以用电脑的鼠标键盘操控手机、无线投屏、录屏，还能把手机当电脑摄像头用，或把某个 App 放进电脑上的一个独立窗口里单独跑。免费、开源、无广告。

全程本地直连（数据线，或同一个 Wi-Fi），画面不经过任何服务器；手机端不用 root、不用装 App，只需在开发者选项里打开调试开关（USB 调试或无线调试）。


----------------------------------------
一、三步开始用
----------------------------------------
1. 把压缩包【解压】到任意文件夹（不要直接在压缩包里运行）。

2. 手机开启「USB 调试」：设置 > 关于手机 > 连续点 7 次「版本号」，返回设置就能看到「开发者选项」，进去打开「USB 调试」。

3. 双击【投屏助手-双击运行.bat】，用支持数据传输的 USB 线连接手机，点「开始投屏」。

首次连接时手机上会弹一个「允许 USB 调试」，点允许即可。顶部「当前设备」卡片显示连接状态，等待授权时显示「等待手机授权」，连上后会显示设备名称、系统版本（如「Android 13」）和 USB / Wi-Fi 标签；多台同时连着时点击设备名称就能切换，未连接时卡片内直接提供「用配对码连接」「输入 IP 连接」和「开启步骤 ?」。

如果 Windows 弹出「Windows 已保护你的电脑」，请确认你从本项目 GitHub Releases 下载了安装包，再按 Windows 提示操作。


----------------------------------------
二、能做什么
----------------------------------------
【开始投屏 / 切到无线 / 无线连接…】
  连上手机后点「开始投屏」立即投屏当前选中的手机。只有数据线连接时，右侧按钮显示「切到无线」，可一键转 Wi-Fi 后拔线；未连接或已连无线时显示「无线连接…」，支持插线切无线、Android 11+ 配对码和输入 IP 连接（见第三节）。

【快捷开关】
  主界面提供「传声音」「投屏息屏」「窗口置顶」「清晰度」快捷胶囊，点一下立即保存，与「设置」里的对应项同步。

【手机当摄像头】（需 Android 12+）
  只投手机的摄像头画面、不投手机屏幕。可选后置/前置镜头、横/竖屏、旋转 180°（手机倒置时修正）、分辨率、初始倍率、补光灯、麦克风，选好点「开始预览」。

  · 手机倒置时勾「旋转 180°（手机倒置时修正）」，在横屏或竖屏基础上再旋转 180°，不是左右镜像。
  · 分辨率按镜头报告的支持列表给。
  · 想用超广角或长焦，就调倍率：投屏中按 左 Alt + ↑ / ↓ 实时变焦，关窗时是多少，助手就记住多少，下次打开面板直接就是那个值。可填范围也按你这台手机上报的读取，不是写死的。（几倍会切到长焦由手机自己决定，各家不同，边按边看画面即可。）
  · 前置和后置各使用手机报告的第一颗镜头。分辨率和变焦范围随所选镜头变化。
  · 手机亮屏被系统抢走摄像头时会自动重连，不用手动重开。
  · 想在会议 / 直播软件里当摄像头用：Windows 上 scrcpy 不提供虚拟摄像头设备，请用 OBS 之类的软件「窗口捕获」这个画面窗口，再由 OBS 输出虚拟摄像头。

【录制屏幕】
  可边投边录（遵循「投屏息屏」「窗口置顶」等设置），也可开启后台录制。后台录制时电脑不显示画面、不播放声音，已开启且能采集的声音仍会写入文件。
  在「设置 > 录制」填好「保存目录」后，点「录制屏幕」会直接按时间戳保存，不再每次弹窗；不填=每次弹窗选择，并自动记住上次目录。
  停止录制时，可直接点主界面功能卡「停止录制」（仅结束录制，不影响正在运行的投屏窗口），也可在顶部「当前设备」卡片点「■ 停止」、在托盘右键菜单点「■ 停止录制」，或在「设备管理」选中设备后点「■ 停止投屏」（非后台录制也可直接关闭录屏窗口）。选 VP8 / VP9 编码，或开启音频并选原始 PCM 时，录屏使用 mkv。

【独立窗口】（需 Android 11+）
  在电脑上单独打开一个手机应用，手机主屏可以继续使用。首次使用默认选「竖屏·手机版面」并勾选「固定分辨率」。勾选时拖动窗口只改变电脑上的显示大小。取消勾选后，安卓虚拟屏会随电脑窗口改变大小，应用可能重新排版。也可选「横屏·平板版面」、跟随设置里的尺寸，或自定义宽高。选好点「打开独立窗口」，关闭窗口时里面的应用默认会一起关闭。
  开启「只投屏，不允许控制手机」时，独立窗口不可用。可以用「开始投屏」只看画面。
  独立窗口播放手机的系统声音，需要 Android 11+。「自动」遵循声音总开关，并在已有窗口播放时静音。「强制播放」允许本窗口播放，即使总开关关闭。「静音」关闭本窗口的声音。
  点「更多应用」可按应用名称或包名搜索，直接点「加入常用」即可收藏并继续浏览。已收藏或内置的常用应用会显示「已在常用」。点「选择应用」返回独立窗口，再点「打开独立窗口」才会启动。「手动输入」可直接输入应用名称或包名。
  「管理常用」里可用「从手机添加」或「手动添加」收藏应用。「移除常用」只会移除快捷项。

【设备管理】
  多台手机的连接、投屏、重命名都在这，见第四节。

【寻找手机】
  手机在线时，点主窗口「当前设备」卡片里的铃铛图标（「寻找手机」），以最大闹钟音量循环播放手机当前的来电铃声，直到点「■ 停止」。手机须通过 USB 或无线 ADB 在线。多台在线时，先按设备名称、连接方式和序列号确认目标，再点「寻找这台」。停止响铃、断开连接或退出助手后，手机会恢复原来的闹钟音量。手机的勿扰规则可能限制闹钟发声。

【文件管理】
  点主界面「文件管理」功能卡打开手机文件管理器：看手机里的文件（名称 / 类型 / 大小 / 修改时间）、上传（可多选，也可把电脑文件直接拖进列表）、下载（多选后挑一个电脑文件夹，自动记住上次保存位置）、新建文件夹、重命名、刷新、删除。数据走 ADB 直连，手机端不用装 App、不用 root；接了多台手机时，窗口顶部可以切换设备。
  拒绝批内重名（含大小写冲突）、文件与文件夹同名，以及下载目录中的链接；请调整名称或保存位置后重试。
  设备探测和下载合并支持关窗取消；下载暂存在所选目录，取消时已完成的文件会保留，正在替换的文件保留原件。
  覆盖授权仅适用于已确认的具体路径，新出现的同名目标会再次确认；可选择链接目录作为保存位置，实际写入路径中的链接和上传目标链接会被拦截。
  合并文件夹时，仅覆盖或跳过列出的冲突项，其余文件继续传输。覆盖后无法恢复。
  打开时会先在后台查一次设备。查询失败会提示「无法读取设备列表，请重试。」取消这次查询则不打开窗口。查询成功但没有在线手机时，会提示「没检测到手机」。
  重命名只改当前目录里的名字：选中恰好一项后点「重命名」或按 F2；多选、没选中时按钮不可用。遇到同名会提示换名，不会覆盖已有文件；名称规则和「新建文件夹」一样，也不能叫「.」或「..」。
  在文件列表里按住鼠标左键拖动就能框选多个文件，文件铺满列表、找不到空白起点时也一样可以从任意一行起手；按住 Ctrl 再框选可在原有选择上追加。单击、双击、把电脑文件拖进来上传都照旧。
  文件列表可以用键盘导航：↑↓ 选文件，→ 或 Enter 进入选中的文件夹，← 返回上一级。打开窗口时焦点就在列表上，不用先点一下；点过按钮后方向键照样有效（导航完焦点会自动回到列表）。焦点在路径框或设备下拉框时，这几个键仍是打字、切设备和「转到」用的，不会被抢。只有恰好选中一个文件夹时才进得去，多选或选中的是文件时按 → / Enter 不会乱跳。按 F2 给选中的一项改名（需要先选中恰好一项）。
  目录里文件多时，进文件夹和刷新也不会明显变慢：手机端会成批读取一批文件的大小和修改时间，列表也是整批填充，等待时下方会显示「正在读取…」。个别手机不支持批量读取、或正好有文件在读取时被删掉，会自动改用稳妥的逐文件方式重读一次，稍慢一点但不会把大小和时间对错文件。
  没读到完整目录时（手机掉线、ADB 没起来、返回被截断），列表会显示「（打不开这个目录）」并提示确认连接后点「刷新」，不会把「没读到」当成「这个文件夹是空的」。读目录在后台进行，等待时显示「正在读取…」；关掉文件管理窗口就会取消这次读取，超时也判「读不到」，不会让界面一直卡着。
  「修改时间」是手机上这个文件的最后修改时间，按电脑的本地时区显示（例如 2026-11-07 15:30）。少数老手机或读不到的系统目录会显示「—」，不影响文件本身的显示和操作；安卓文件系统通常不提供创建时间，所以这里给的是修改时间。列表仍按名称排序，点列头不会排序。
  上传 / 下载时，文件列表下方会出现进度条：下载单个文件按「电脑上已收到多少字节 ÷ 手机上文件大小」显示真实百分比；上传、下载整个文件夹或多选时按已完成的项数一格一格前进，只传一个大文件时显示滚动的「传输中」。ADB 被程序调用时不会实时吐进度，所以上传这里不会编一个假的百分比；传完进度条自动收起。中途关窗会立刻停止整批，进度条直接收起，不会显示成 100%。
  文件管理里的防误删：上传 / 下载遇到同名文件会先问「覆盖 / 跳过 / 取消」（默认停在「取消」），不会闷头把原件替掉；删除会列出待删项及类型再确认，只作用于当前目录里选中的那些名字，在内部存储之外的位置还会再确认一次。名称含特殊字符的条目会隐藏并且不可操作，避免删错位置。
  上传 / 下载 / 删除这类批量操作，从开始就把手机和当前目录固定住：处理期间顶部的设备下拉框会锁定并提示「正在处理，等这一批完成再切换设备」，不会把同一批剩下的文件发到另一台手机、或删到别的目录。中途关掉窗口会立即停止整批，不再启动后续项。
  重要提示：删除文件不进回收站、无法恢复！


其它随手可用的：

· 普通文件拖进投屏窗口后默认传到手机「内部存储 > Download」，APK 会请求手机安装。安装或传输结果可在投屏日志窗口查看。
· 点主界面右上角「快捷键」可查看常用快捷键（全屏、息屏、旋转、复制粘贴等）。
· 关闭助手窗口（×）会一并停止投屏；想让投屏继续、只把助手收起来，请点最小化（–）。正在录屏时会先问你确认，确认后先尝试正常停止录制。
  录屏停止超时后，可选「继续等待」「强制结束」或「取消」。强制结束可能导致视频文件损坏或无法播放。强制结束后会提示「已强制结束录屏，请检查视频文件。」；异常退出会提示「录屏异常结束，请检查视频文件。」
· 想让最小化后任务栏不占位：到「设置 > 窗口」勾上「最小化时收起到系统托盘」。勾上后点最小化，助手会收进屏幕右下角的托盘区，投屏、录制照常运行；单击或双击托盘图标还原窗口，右键图标可显示窗口、直接停止录制 / 全部会话，或退出助手。
· 助手同一时间只开一个，重复双击只会把已有窗口调到最前。


----------------------------------------
三、无线投屏怎么连
----------------------------------------
点「无线连接…」时可选择三种连接方式（未连接时主界面的「当前设备」卡片也直接提供「用配对码连接」和「输入 IP 连接」入口；只插着 USB 线时主界面右侧按钮会直接显示「切到无线」）。

【插数据线切到无线】
  先用数据线连好手机，并在手机上允许 USB 调试。等无线投屏画面出现后再拔线。
  插好线、手机上点过「允许 USB 调试」后点「继续」；这时还没检测到手机，窗口会给你「重试」或改走「输入 IP 连接」，不用退回主界面重来。
  插线转无线成功后，拔线仍可在主界面或「设备管理」查看运行状态并点「停止」。若显示「无线连接失败」，先别拔线。确认手机已允许 USB 调试，并和电脑连着同一个 Wi-Fi。可点「查看原因」看详情。
  手机重启后若连不上，重新插线启用网络连接。

【用配对码】（需 Android 11+，全程不用插线）
  先在手机开「开发者选项 > 无线调试」，点「使用配对码配对设备」，从弹窗中抄下「IP 地址和端口」和 6 位配对码。配对后助手会尝试自动连接。若提示「请手动填写连接端口」，从「无线调试」主界面取端口。
  配对码过期后重新打开配对弹窗。只要手机还记着这台电脑的配对记录，重连可直接用当前连接地址。

【输入 IP 连接】
  已配对：填「无线调试」主页的 IP 和连接端口。
  插线转无线：填手机的 Wi-Fi IP，端口通常为 5555。

  无线调试的连接端口可能变化。若旧地址连不上，请以手机当前显示的地址为准。手机已经连上时，可直接点「开始投屏」。

连过的设备会自动记住。没有已连接设备时，点「开始投屏」「文件管理」等主功能，助手会尝试连接未标记「不自动连」且当前可达的已记住设备。

设备状态刷新和已记住设备重连在后台进行。打开主窗口时「当前设备」显示「正在检测手机…」，第一次查询失败后会在后台再试一次。显示「连接状态待确认」时，暂时无法确认手机连接状态，切回窗口会重试。忙碌期间的刷新请求会合并，空闲后补查。自动重连成功后，主窗口立即更新连接状态。关闭「设备管理」后，主窗口会刷新连接状态。没有在线设备时，「等待手机授权」提示解锁手机并点「允许 USB 调试」，「手机离线」提示重新插拔数据线，或检查 Wi-Fi 后重新连接。若重试仍失败，可打开「设备管理」，点「查看原因」。「设备管理」刷新失败时会显示『连接状态待确认，请点击「刷新」重试。』原列表保留，依赖连接状态的操作要等刷新成功后才能使用。文件管理里提示「没检测到手机，请先连接手机再点刷新。」时，先连好手机再刷新。

等待框会显示当前步骤，例如「正在读取设备列表…」「正在配对并连接手机…」。点「取消」可结束本次等待，已经完成的配对、连接或停止操作会保留。文件管理读取目录时显示「正在读取…」，关窗会停止读取，读取超时或失败时显示「（打不开这个目录）」。

老是中途断开？在「设置 > 常用」勾上「自动重连已记住的无线设备」。会跳过标记「不自动连」的设备。


----------------------------------------
四、多台手机怎么管
----------------------------------------
点「当前设备」卡片右侧的「设备管理」打开「设备管理」（多台同时在线时，也可在主界面卡片里点击设备名直接切换）。「设备管理」刷新失败时会显示『连接状态待确认，请点击「刷新」重试。』原列表保留，依赖连接状态的操作要等刷新成功后才能使用。

按钮分两组：

  投屏组  「连接」只负责把没连的设备连上；连上后再点「▶ 投屏」开镜像窗口。双击某一行 = 顺手帮你做下一步（没连就连、已连就投）。
  管理组  设为默认（多设备时默认投它）、断开（先关掉这台的投屏窗口、再断掉无线连接；USB 设备请拔线）、重命名（起个好认的名字，如「客厅电视」）、忘记（从「已记住」里去掉，它的自定义名字和默认标记一并清掉；设备还连着时点不动，要先断开或拔线）、不自动连。

开启「不自动连」后，助手会跳过这台手机。已经配对的手机仍可能自己连上。要取消配对，请在手机的「无线调试」里忘记这台电脑。

想同时投多台：按住 Ctrl 多选后点「▶ 投屏」，或直接「全部投屏」。每台各开一个窗口、互不干扰，窗口标题就是设备名（录制和摄像头的窗口会多带「· 录制」「· 摄像头」后缀，一眼能分清）。正在投的会标「▶ 投屏中」，「■ 停止投屏」会停止所选设备的投屏、录屏（含后台录制）和摄像头。

多台设备符合当前功能的要求时，优先使用候选列表中的默认设备，否则请手动选择。只有 USB 设备时，「切到无线」会让你从多台 USB 设备中选择要切换的设备。


----------------------------------------
五、设置里有什么
----------------------------------------
点窗口右上角「设置」。左侧按分类切换，右侧是可调项，改完点「保存」才会记住，下次沿用。

  常用：投屏卡顿时可调低「清晰度」，0=不限制画面大小。怕投屏时手机自己休眠，可以勾「投屏时保持手机唤醒」。
  画面：「帧率」限制每秒画面更新次数，0=不限制。「画质」的数字越高通常越清楚，也更占网速，0=用默认。改过视频编码后打不开时，可换回默认的 H.264。
  声音：想听手机里正在播放的内容，选「手机正在播放的声音」，声音会改从电脑播放。想收周围的声音，选「手机麦克风」。需要 Android 11 或以上，Android 11 请先解锁再投。
  控制：键盘 / 鼠标模式、只看不控、关窗顺手息屏、显示触摸点、手柄
    只看不控时，保持唤醒、投屏关屏、显示触摸点和关窗息屏暂不生效。「显示触摸点」只标出手指实际触摸手机的位置。
  窗口：全屏、窗口置顶、无边框（关窗按左 Alt+Q，也可在主界面点「■ 停止」）、最小化到系统托盘
  独立窗口：分辨率（可自定义）、界面缩放、「隐藏独立窗口的系统栏」（同时隐藏状态栏和导航栏）
    自定义尺寸时，宽高不填=自动。只想调字和按钮大小，可以只填 DPI。一般直接用「界面缩放」里的「小」「中」「大」即可。
  录制：保存格式、录制时长、后台录制、保存目录（不填=每次弹窗选择）
  通用：自动刷新状态、其它命令行参数和自定义程序路径。scrcpy 路径不填=用自带的。adb 路径不填=先找所选 scrcpy 同目录的 adb，再找助手自带的。
    参数之间用空格分隔。含空格的值用双引号包住，例如 --window-title="Living Room"。

设置无法保存时会提示「保存设置失败」，本次修改仅在当前运行中生效。请确认软件目录可写。
加载时，单个无效设置使用默认值，其余有效设置和设备记忆照常恢复。整份设置文件无法读取时，下次保存会在软件目录保留一份原文件备份（.bak）。

不确定某项是做什么的，把鼠标停在它上面会有中文说明。看不懂的保持默认即可，不影响使用。
改乱了想还原：设置窗口左下角有「恢复默认」，一键复位。

「开始投屏时熄灭手机屏幕」只熄灭手机屏幕，电脑画面继续显示。按手机电源键或在投屏窗口按左 Alt+Shift+O 点亮。

关闭助手后，手机默认仍保持无线连接。想关助手时一并断开助手记住或启动过的无线设备，勾「关闭助手时断开无线连接」。
若提示「无线连接未全部断开」，可查看「断开失败」和「尚未处理」的设备，再选「仍然退出」或「取消」。

六、遇到问题怎么办
----------------------------------------
· 双击后窗口一闪而过 / 打不开
  先确认已完整解压、且 .bat 和其它文件在同一个文件夹里。若提示「无法启动投屏」，可点「查看原因」看详情。若提示「投屏窗口没能打开」，到「设置 > 常用」勾选「显示投屏日志窗口」并保存，再投一次看报错。

· 把文件拖进投屏窗口显示「禁止」图标
  助手正以「管理员身份」在跑——Windows 不允许普通的文件资源管理器把文件拖给管理员权限的窗口。完全关掉助手，改成普通双击【投屏助手-双击运行.bat】重新打开即可（快捷方式里若勾了「以管理员身份运行」也要取消）。助手本来就不需要管理员权限。

· 提示找不到设备
  确认手机已打开「USB 调试」，并解锁手机接受授权。仍找不到时，换一根支持数据传输的 USB 线，直插电脑 USB 口。

· 能看到画面，但键鼠点不动手机
  先确认「设置 > 控制」里的「只投屏，不允许控制手机」已关闭，键鼠模式改回「默认」。若投屏日志里出现 INJECT_EVENTS 权限错误，检查手机开发者选项是否另有「USB 调试（安全设置）」。部分机型开启这项后需要重启手机。

· 无线连不上
  确认手机和电脑连的是同一个 Wi-Fi。用配对码时还要确认手机停在「无线调试」那一页别退出。若提示「请手动填写连接端口」，在手机「无线调试」主界面的「IP 地址和端口」里取冒号后的数字。

· 投屏出来的手机画面发虚模糊（指镜像的手机画面，不是助手界面）
  右键 scrcpy.exe >「属性」>「兼容性」>「更改高 DPI 设置」> 勾选「替代高 DPI 缩放行为」。（助手界面本身已适配高 DPI；若助手界面发虚，多半是旧版本。）

· 画面花屏、偏色或整块变黑
  到「设置 > 画面」把「解码方式」改成「软件解码」后重试。若还是花屏，可打开投屏日志窗口看报错。
  若编码选的是 H.265，先确认 scrcpy 是 5.0.1 或更新：5.0 在某些显卡驱动上硬件解码 H.265 会绿屏、花屏，5.0.1 已修好，升级后继续用「自动」就行，不必长期吃 CPU。

· 摄像头打不开，报「Camera configuration error」
  先选较低的分辨率再打开摄像头。只看到通用档位时，可以先试「中」。反复打不开时，可查看同目录的「投屏助手-错误日志.txt」。

· 摄像头画面上下颠倒
  手机整个倒过来放时，画面会跟着转半圈。在「手机当摄像头」面板里勾「旋转 180°（倒置修正）」——它是在横屏或竖屏基础上再旋转 180°，不是左右镜像。

· 手机一亮屏，摄像头就断开
  安卓的系统行为——亮屏时系统（如人脸解锁）优先级更高，会把摄像头从 scrcpy 手里抢走，scrcpy 挡不住。助手检测到后会自动重连，底部有提示。想少被打断，可在使用期间开勿扰，或关掉「抬起亮屏 / 人脸解锁」。

· 中文怎么输入
  投屏时用默认键鼠模式即可。中文可用 Ctrl+V 粘贴，也可选「模拟实体键盘」，用手机输入法打字。用「模拟实体鼠标」时，按左 Alt 或左 Win 可把鼠标指针切回电脑。

· 独立窗口里微信 / QQ 显示不全、字太大、有重影
  应用可能使用了平板布局。打开「独立窗口」时可将「窗口比例」选为「竖屏·手机版面」。若拖动窗口或最大化时画面反复变化，可勾选「固定分辨率」。

· 应用双开 / 分身在独立窗口里黑屏
  安卓的限制——分身跑在另一个用户身份下，且部分应用拒绝在虚拟屏上显示。双开 / 分身请改用普通「投屏」镜像手机主屏，在手机上打开。

· 同一台手机开了多个窗口，只有一个有声音
  普通投屏的后开窗口若发现同设备已有窗口播放声音，会自动静音。先关掉原来播放声音的窗口，再重开需要声音的窗口即可。「独立窗口」可选择「播放」，允许本窗口同时播放。

· 文件管理里某个目录打不开，或删不掉里面的东西
  ADB 只能读写它有权限的位置。内部存储（/sdcard 及其子目录，如 Download、DCIM）一般都能读写；能否修改系统目录或应用私有目录取决于 Android 给 ADB 的权限。遇到权限错误时，请换到自己的文件夹再试。另外：文件管理里的「删除」不进回收站，手机上删掉就找不回来，所以每次都会先弹一次确认。

· 删一个很大的文件夹，中途会不会删一半？
  不会中途超时被掐断：删除用的是不限时的通道，界面也还能刷新。但如果删除过程中你关掉了窗口，或设备端没返回明确结果，助手会停止后续项。若窗口仍然打开，会显示「已停止继续删除」。这时先点「刷新」重新看一遍目录，别直接重试整批，也别以为「报了失败」就等于什么都没删。

· 批量传文件或删除时，切了设备、或直接关了窗口会怎样？
  切设备不会被接受：整批从开始就锁定在开始的那台手机和那个目录，顶部下拉框也会暂时锁住并提示「正在处理，等这一批完成再切换设备」，等这批做完再切。关窗口会立刻中止整批，不再启动剩下的项；已经传过去 / 已经删掉的部分不会自动回滚。重新打开「文件管理」后先点「刷新」看清现状再决定要不要补做，别把整批直接重来一遍（删除尤其不能重试整批）。

· 上传 / 下载时遇到同名文件会怎样？
  会先弹窗列出冲突项，可滚动查看完整清单。合并文件夹时，仅覆盖或跳过列出的冲突项，其余文件继续传输。覆盖后无法恢复。
  默认停在「取消」。传输开始前选「取消」会取消整批；传输途中再次出现确认框时，选「取消」会停止后续传输，已完成的文件会保留。上传使用手机目标目录下的临时空间。

· 下载时提示「文件名含 Windows 不允许的字符」，或存下来的文件名不对
  手机上允许 : * ? " < > | 以及以点 / 空格结尾的名字，Windows 不允许；这类文件无法直接下载，助手会明确列出并跳过，请在手机上改名后再试。其余文件会按完整文件名保存到你选的文件夹，不会再让 ADB 自己拼文件名，也就不会出现名字被截断或存成一个奇怪的「.」文件。

文件夹里的 scrcpy-helper.ps1、scrcpy.exe 等是程序文件，平时不用打开，只要它们和 .bat 在同一个文件夹里即可。
